# 🌊 Inka Sub: Misión Mar de Grau

Videojuego educativo 2D en pixel art sobre el **ODS 14: Vida Submarina**. Pilotas un submarino científico peruano con identidad andina y limpias el Mar de Grau de monstruos hechos de plástico, usando como arma bacterias *Ideonella sakaiensis*, capaces de degradar el plástico PET.

## 🎮 Cómo se juega

| Acción | Control |
|---|---|
| Moverte | `W` `A` `S` `D` |
| Apuntar | Mouse |
| Disparar | Clic izquierdo |
| Recargar | `R` |
| Dash (se desbloquea con 2 bacterias) | Clic derecho |
| Disparo Doble Disolvente (se desbloquea con 3 bacterias) | `K` |
| Hablar / recolectar | `E` |
| Pausa | `Esc` o `P` |

## ✨ Características

- Combate contra el **Fantasma de Red** y el **Conglomerado Tóxico**, con oleadas y zonas de combate.
- **Animales del mar peruano** que cuentan cómo los afecta el plástico (tortuga verde, pingüino de Humboldt, lobo marino chusco y mero gigante).
- **Datos científicos** reales al recolectar bacterias.
- **Jefe final: el Iceberg de Basura.** Tiene 3 fases, ojos débiles que se abren y se cierran, lluvia de desechos, microplásticos y un tentáculo.
- **Puntos de control:** cangrejos peludos (*Cancer setosus*) con basura en su caparazón. Si pierdes, puedes continuar desde el último.
- Pensado para estudiantes de 10 a 16 años (10 a 15 minutos de juego).
